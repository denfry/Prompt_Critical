# Видеогайд Prompt Critical: серия эпизодов

Статус: черновик сценария на согласование (2026-11-19). Съёмка и монтаж начинаются после того, как сценарий эпизода 0 утверждён.

## Решения

- Серия: обзор на 3–4 минуты, потом по эпизоду на каждую эру и сквозную систему, 6–10 минут каждый.
- Голоса нет. Смысл несут текст на экране, графика поверх кадра и звук самой игры, под ними музыкальная подложка.
- Языки: RU и EN. Это одна композиция с переменной `lang`, рендерится два раза. Картинка общая, отличаются только
  надписи, поэтому любая правка монтажа сразу попадает в обе версии.
- Кадры: `FilmRecorder` (камера по ключам, 60 fps, кадр в кадр) и площадка `filmset`, как в трейлере M2.
- Графика и сборка: HyperFrames (HTML-композиция поверх видеодорожек). Надписи, схемы, стрелки на приборах, плашки эр
  и таймлайн удобнее верстать в HTML, чем городить в ffmpeg `drawtext`. `edit.py` остаётся для трейлера.
- 1920×1080, 60 fps. Отдельные вертикальные шорты нарезаются из эпизодов потом.

Главная статья расходов здесь съёмочные площадки. Сейчас `filmset` строит только I0 (котельная, литейка, шахта).
Для эпизодов 2–8 и для обзора нужно собрать и запустить площадки поздних эр, чтобы машины в кадре реально работали.
Скриншоты в README (домна, буровая, ПГУ, каскад центрифуг, ВВЭР) показывают, что такие сцены в игре уже есть,
их надо перенести в `filmset` с ракурсами для камеры.

## Эпизод 0: обзор (≈3:30)

Ритм: склейки по долям такта, на смене эры хлёст (whip) с размытием, на приборах резкий наезд (punch-in), в моменты
аварий короткие замедления. Типографика инженерная: моноширинные коды (`I2`, `T3`, `A4`), тонкие линии выносок,
жёлтый «предупредительный» акцент. Обычные экраны в духе трейлера-«маркетинга» не используем.

Обозначения: **[есть]** шот снимается на текущей площадке, **[нужна]** нужна новая, **[GUI]** открыт щит машины.
