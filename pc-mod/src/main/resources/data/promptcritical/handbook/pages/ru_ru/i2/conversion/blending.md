# Компаундирование бензина и лаборатория

Товарный бензин не выходит ни из одной установки: его смешивают из компонентов, у каждого свои октановые числа, давление паров, сера, бензол, ароматика, олефины и плотность. Прямогонный бензин атмосферной колонны (ОЧИ 68), риформат (98), бензин каткрекинга (91,5) и н-бутан с ГФУ (93, но давление паров 360 кПа). У [станции смешения](item:promptcritical:gasoline_blender) на каждый — регулирующий клапан в м³/ч, смесь идёт в её резервуар; товарный бензин уходит снизу.

Найти рецепт — задача линейного программирования: максимум маржи при ограничениях на ОЧИ, ОЧМ, давление паров (индекс Chevron ДНП^1,25), серу, бензол ≤ 1 %, ароматику ≤ 35 %, олефины ≤ 18 % и плотность. «Нормаль-80» из этих четырёх сделать можно (например, 2,09 м³/ч прямогонного, 0,64 риформата, 5,0 бензина каткрекинга); АИ-92 — нельзя: для ОЧМ 83 нужен октан без ароматики, а это алкилат, которого пока нет. Компьютер рядом со станцией видит её как pc_tank: getBlendData() отдаёт компоненты, марку, анализатор и паспорт, setValves(a, b, c, d) задаёт рецепт.

Настоящая смесь немного расходится с линейной моделью: октановые числа не складываются по объёму точно. Рецепт на границе ОЧМ уходит из марки на полпункта, и его поправляют по измерениям.

Качество не видно, пока его не измерят. [Поточный анализатор](item:promptcritical:quality_analyzer), касающийся станции, непрерывно показывает ОЧИ, ОЧМ и ДНП резервуара, но дрейфует: около 0,3 пункта за час работы. [Пробоотборником](item:promptcritical:sample_bottle) по станции или по любому баку с компонентом бензина берут пробу. [Лаборатория](item:promptcritical:quality_lab) прогоняет её на моторных установках CFR 40 минут физического времени и выдаёт результат с воспроизводимостью ASTM (±0,7 пункта октана, ±5 % по сере). Проба партии станции ещё и записывает в станцию паспорт партии и выдаёт [паспорт](item:promptcritical:batch_certificate). По свежему паспорту кнопка «Калибровка» обнуляет дрейф анализатора. Долили смесь в резервуар — паспорт недействителен.
