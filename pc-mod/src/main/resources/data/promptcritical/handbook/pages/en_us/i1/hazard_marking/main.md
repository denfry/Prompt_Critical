# Hazard marking

A [safety sign](item:promptcritical:hazard_sign) hangs on a wall. Right-click picks the next sign of its group, sneak and right-click the next group: warning (fire, explosion, toxic, corrosive, radioactive, voltage, gas cylinder, danger of asphyxiation), prohibition, mandatory, GHS pictograms. A mandatory sign — wear a hard hat, a gas mask, ear muffs, a harness — reminds anyone within 4 blocks who walks past without it.

An [NFPA 704 diamond](item:promptcritical:hazard_diamond) and an [ADR placard](item:promptcritical:un_placard) hang on a tank and read what is in it: right-click for the UN number, the Kemler hazard code and the diamond health-fire-reactivity-special. Gasoline is UN 1203, code 33, 1-3-0; chlorine is UN 1017, code 268, 4-0-0-OX; liquid nitrogen is 3-0-0-SA — simple asphyxiant.
